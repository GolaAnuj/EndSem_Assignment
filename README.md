# AITR Lab 02 — Prompt 01 and Prompt 02

**Research area:** The Influence of Citation Formatting on Human Trust in Fabricated References

This workspace intentionally covers **only Prompt 01 (accountable research workspace)** and **Prompt 02 (evidence-based research-gap extraction)** from the assignment sheet. It does not claim that a baseline has been implemented, experiments have been run, participants have been recruited, or results have been measured.

## Files

- `research_decisions.md` — scope summary, verified/inferred/unknown ledger, decisions, reasons, evidence, and next actions.
- `gap_matrix.md` — five candidate computationally testable gaps, review evidence, proposed questions, evidence that would test each gap, risks, and ranked top three.
- `source_verification_register.md` — primary-source checks already made and sources that still need full-text/method verification.
- `prompt_log.md` — adapted Prompt 01 and Prompt 02 used for this checkpoint.
- `review_basis/ACM_Final_Review_Paper.pdf` — the prior ACM-formatted review used as the main evidence base.
- `review_basis/Source_Review_Paper.pdf` — the supplied source version of the prior review paper.
- `review_basis/main.tex`, `references.bib`, and `Figures/` — portable LaTeX source assets for tracing claims back to the review.

## Boundary of this week's work

Completed here: define the workspace and scope; extract and rank candidate gaps; flag evidence and novelty checks that remain. Not completed: Prompt 03 literature-to-experiment mapping, final research-question approval, participant study, ethics approval, dataset collection, coding, baseline implementation, or experimental results. Those are later stages and must not be implied by this checkpoint.

## Evidence labels

- **VERIFIED** — directly checked in the supplied review or a primary-source page/abstract linked in the source register.
- **INFERRED** — a research interpretation drawn from the reviewed evidence and requiring testing.
- **UNKNOWN** — not established by the currently available evidence, or requires a broader/full-text check.
